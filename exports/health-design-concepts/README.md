# Luminary Health design directions

These are comparison designs only. They do not replace the production Health screen.

1. **Daily brief** — puts today's workout, volume, and the next training moments in the first viewport. Best when Health should feel fast and decisive.
2. **Week atlas** — makes the weekly plan the primary interface and expands the selected day inside a continuous timeline. Best for planning and review.
3. **Body & load** — connects workout volume to a physical focus map, while explicitly identifying unavailable Health data. Best if recovery context becomes central.
4. **Coach stream** — reveals one recommendation at a time, then progressively exposes the plan, substitutions, and optional connections. Best for adaptive guidance.

All four preserve Luminary's obsidian surfaces, single blue accent, no-line hierarchy, editorial Manrope/Inter-style type balance, 44px controls, visible focus states, and reduced-motion behavior.

Open `http://127.0.0.1:60180/exports/health-design-concepts/` while the local comparison server is running. Use the four controls in the header to switch directions.
